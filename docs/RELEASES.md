# 版本记录

## 2026-10-14 · 首个源码基线

包含网页、比赛状态机、评分与统计、C# 桥接及通用部署工具。

最近调整：手动空闲切图使用原生联网退场流程；加载新地图前同步参数；退场和初始化期间拦截选队；自由游玩热身 120 秒、排位到场等待 300 秒。

已验证：网页与桥接回归、插件编译；在线原版地图切换、原版切自定义地图；自由游玩进入排位准备、自动分配与出生，以及取消排位后恢复自由游玩。

尚需真人验证：12 人正式开赛、整场换边与结算后返回自由游玩，以及全部自定义地图的实战表现。少量玩家的切换测试不等于全部地图与并发人数验收。

历史插件仍使用 v0.4.2 标记，首个 Git 提交固定这一源码基线。此后以提交和发布标签追踪构建，避免仅凭旧插件版本号判断内容。
